# v0.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish an immutable, verified v0.1.0 public-beta package and GitHub Release.

**Architecture:** Land the stable-tag install instruction before tagging. Build the release ZIP only from the verified final `main` tree, validate the archive independently, then bind the tag and GitHub Release to that exact commit.

**Tech Stack:** Markdown, Git, Node.js 18+, ZIP, SHA-256, GitHub CLI and Actions.

## Global Constraints

- Version is exactly `0.1.0`; tag is exactly `v0.1.0`.
- Installable package contains only the top-level `loop-designing/` folder.
- Do not create or overwrite a tag or release until all checks pass.
- Release remains public beta and requires Node.js 18+.
